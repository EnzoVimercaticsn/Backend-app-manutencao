API de Acompanhamentos

Rotas públicas para salvar e consultar acompanhamentos de restaurante.

GET/health

Verifica se o servidor está funcionando.

{ "status": "ok" }

GET/api/acompanhamentos

Lista todos os acompanhamentos, ordenados do mais recente para o mais antigo.

[
  {
    "id": 1,
    "restaurante": "RS01",
    "data_visita": "2026-08-10",
    "hora_visita": "11:45",
    "servico": "Almoço",
    "itens": []
  }
]

GET/api/acompanhamentos/:id

Consulta um acompanhamento completo pelo ID, incluindo itens e imagens.

Exemplo: /api/acompanhamentos/1

POST/api/acompanhamentos

Salva um acompanhamento usando multipart/form-data.

  • restaurante, data_visita, hora_visita
  • servico, verificado_csn, validado_sodexo
  • itens como JSON em texto
  • Imagens nos campos item_1, item_2 ou imagem_1
{
  "sucesso": true,
  "id": 123
}
Rotas abertas: não é necessário token, login ou autenticação.
